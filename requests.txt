# API Requests for AI Pitchdeck Content Generator

## Authentication
# Login (get token)
curl -X GET "http://localhost:8000/auth/login"

# After OAuth flow completes, you'll receive a token in the callback response

## Check Authentication
# Test if authentication is working
curl -X GET "http://localhost:8000/protected" \
  -H "Authorization: Bearer default_user"

# Response:
# {
#   "message": "Authenticated as default_user"
# }

## Get Templates
# List all presentation templates in the Templates folder
curl -X GET "http://localhost:8000/templates" \
  -H "Authorization: Bearer default_user"

# List templates from a specific folder
curl -X GET "http://localhost:8000/templates?folder_name=CustomTemplates" \
  -H "Authorization: Bearer default_user"

# Response:

## Generate Content
# Generate content for placeholders based on a prompt and template ID
curl -X POST "http://localhost:8000/generate-content" \
  -H "Authorization: Bearer default_user" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Create a pitchdeck on Facebook",
    "template_id": "1NQ9KSUawwHVGP4AGQpLErGMN9BnCX6GvHiBdB32wdTc"
  }'
